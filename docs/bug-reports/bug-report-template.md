# Bug Report Template

| Field | Details |
|---|---|
| Bug ID | `BUG-###` |
| Title | Short, clear summary of the problem |
| Environment | Environment, browser, and execution date |
| Severity | Critical / High / Medium / Low |
| Priority | High / Medium / Low |
| Preconditions | Required starting state |
| Steps to reproduce | Numbered, repeatable steps |
| Actual result | What happened |
| Expected result | What should happen |
| Evidence | Screenshot, video, log, or URL |
| Status | New / Open / Fixed / Retest / Closed |
